Step 1 — Choose Your Path
⭐ Best for You
Software Engineer (DSA Track)
High Demand

Most accessible path from your current role. Land at product companies like Razorpay, Zepto, Flipkart or service giants like TCS/Wipro at 2–3× your current salary. Skills are timeless and transferable.

Target CTC ₹6 – 12 LPA in 6–9 months
DSA Java / Python LeetCode System Design Basics GitHub Portfolio OOPs / DBMS
12-Month Roadmap — SWE / DSA
1
Month 1 – 2 · Foundation
Revive Your CS Core

Brush up on the fundamentals before DSA or interviews.

  • Pick ONE language: Java or Python (Python recommended for speed)
  • Revise OOPs, Arrays, Strings, Linked Lists, Stacks, Queues
  • Revise DBMS basics — SQL queries, joins, normalization
  • Revise OS concepts — processes, threads, memory
  • Create a GitHub profile + upload 2 mini projects from college
  • Solve 20 LeetCode Easy problems
2
Month 3 – 5 · Core DSA
Crack the Coding Round

This is the filter for 90% of tech companies. Focus is key.

  • Trees, Graphs (BFS/DFS), Recursion, Backtracking
  • Dynamic Programming (top 20 patterns)
  • Sorting & Searching algorithms
  • Solve 150+ LeetCode problems (60 Easy, 70 Med, 20 Hard)
  • Complete Striver's SDE Sheet or NeetCode 150
  • Start appearing in weekly LeetCode contests
3
Month 6 – 8 · Projects + Portfolio
Build What Gets You Hired

Showcase real work — especially for product companies and startups.

  • Build 2 solid full-stack or backend projects (with README)
  • Deploy them on Render/Vercel with live links
  • Learn System Design basics — load balancers, caching, DB design
  • Contribute to 1–2 open source repos (optional but impactful)
  • Polish LinkedIn: headline, about, skills, projects section
  • Write your ATS-optimized resume (1 page, results-focused)
4
Month 9 – 12 · Apply + Negotiate
Land the Offer

Now hit the job market systematically and confidently.

  • Apply to 10–15 companies per week on Naukri, LinkedIn, Unstop
  • Target: Startups (Series A–C), mid-size product companies first
  • Prepare behavioral answers (STAR format) for HR rounds
  • Do 3–5 mock interviews on Pramp or with peers
  • Never reveal current salary — anchor on market rate
  • Negotiate: even ₹8 LPA is 4× your current package!
Data Analyst
Stable & Accessible

One of the most accessible high-paying paths for CSE grads in 2026. High demand across banking, e-commerce, healthcare. Less competitive than SWE in terms of DSA.

Target CTC ₹5 – 10 LPA in 6–8 months
SQL Python (Pandas) Power BI / Tableau Excel Statistics Data Storytelling
8-Month Roadmap — Data Analyst
1
Month 1 – 2 · SQL + Excel
Master the Must-Have Tools
  • SQL: SELECT, JOINs, subqueries, window functions, GROUP BY
  • Practice on Mode Analytics, HackerRank SQL, LeetCode DB
  • Advanced Excel: PivotTables, VLOOKUP, charts
  • Start Python basics: variables, loops, functions
2
Month 3 – 5 · Python + Visualization
Analyze & Visualize Data
  • Pandas, NumPy, Matplotlib, Seaborn
  • Power BI or Tableau — build 2 interactive dashboards
  • Statistics: mean, median, std dev, correlation, A/B testing basics
  • Complete 3 projects from Kaggle or real-world datasets
3
Month 6 – 8 · Portfolio + Jobs
Build Portfolio & Apply
  • Upload 3 case study projects on GitHub/Notion/Tableau Public
  • Target: BFSI, e-commerce, healthcare companies
  • Apply on Naukri, LinkedIn with "Data Analyst", "Business Analyst" keywords
  • Prepare for SQL interview rounds (most common filter)
AI / ML Engineer
🔥 Hottest 2026

Highest earning potential but requires the most time to become interview-ready. Great long-term bet. Fastest growth trajectory in India right now.

Target CTC ₹8 – 20 LPA in 12–18 months
Python PyTorch / TensorFlow ML Algorithms Mathematics NLP Basics Hugging Face
12–18 Month Roadmap — AI/ML
1
Month 1 – 3 · Python + Math
Build the Foundation
  • Python: OOPs, Pandas, NumPy, Matplotlib
  • Math: Linear Algebra, Calculus, Probability, Statistics
  • Course: Andrew Ng's Machine Learning Specialization (Coursera)
  • Solve basic ML problems on Kaggle
2
Month 4 – 8 · Core ML + DL
Algorithms & Deep Learning
  • Supervised, Unsupervised, Reinforcement Learning concepts
  • Neural Networks, CNNs, RNNs with PyTorch or TensorFlow
  • NLP basics: tokenization, embeddings, transformers
  • Complete 2 ML end-to-end projects (EDA → Model → Deploy)
3
Month 9 – 12 · Specialize + Deploy
Stand Out with GenAI Knowledge
  • Learn LangChain, RAG pipelines, prompt engineering
  • Hugging Face models — fine-tuning basics
  • Deploy a model using FastAPI or Streamlit
  • Target: AI startups, product companies, analytics firms
Cloud / DevOps Engineer
Evergreen Demand

Certification-driven path — fastest salary jump possible. AWS/Azure certifications alone can get you interviews. Every company is on cloud migration right now.

Target CTC ₹7 – 15 LPA in 8–12 months
AWS / Azure / GCP Linux Docker Kubernetes CI/CD Terraform
10-Month Roadmap — Cloud / DevOps
1
Month 1 – 3 · Linux + AWS Basics
Ground Zero
  • Linux: file system, shell scripting, permissions, cron jobs
  • Networking basics: DNS, HTTP, TCP/IP, firewalls
  • AWS free tier: EC2, S3, IAM, VPC, RDS
  • Target: AWS Cloud Practitioner certification (Month 3)
2
Month 4 – 7 · DevOps Tools
Docker, Kubernetes, CI/CD
  • Docker: containerize an app, build Docker images
  • Kubernetes: pods, deployments, services, Helm basics
  • GitHub Actions / Jenkins for CI/CD pipelines
  • AWS Solutions Architect Associate certification (Month 7)
3
Month 8 – 10 · Jobs
Certifications → Interviews
  • Build 2 cloud projects (auto-scaling web app, serverless pipeline)
  • Apply to DevOps/Cloud roles on Naukri, LinkedIn
  • Target: IT service firms, cloud consulting, startups
  • Prepare for scenario-based interview questions

💡 Power Tips for Women in Tech 2026
🎯 Pick ONE path and stay consistent. Don't switch between DSA and ML every month. Depth beats breadth in tech hiring.
💰 Never reveal your current ₹16K salary. When asked, say "I'm targeting market rate for this role, around ₹X LPA." This alone can add ₹2–3 LPA to your offer.
🌐 LinkedIn is your biggest asset. Update your headline to your target role, add skills, post your project updates weekly. Recruiters will find you.
👩‍💻 Target women-in-tech programs: Google STEP, Microsoft LEAP, Walmart's SheCodes, and Amazon WOW all actively recruit women engineers with higher consideration.
📊 Track your progress weekly. Set a goal: e.g., 3 LeetCode problems/week, 1 chapter/week. Use Notion or a simple sheet to stay accountable.
🤝 Community matters. Join LinkedIn groups, Women Who Code India, WiDS (Women in Data Science). Referrals from network land 3× more interviews than cold applies.
